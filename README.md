# ดมยาแคร์ (AnesCare)

แอปเตรียมความพร้อมก่อน–หลังการระงับความรู้สึก สำหรับผู้ป่วยและญาติ
พัฒนาเป็น PWA (Progressive Web App) — ใช้งานผ่านเว็บเบราว์เซอร์ และสามารถ "เพิ่มลงหน้าจอโฮม" ให้เหมือนแอปจริงได้ ใช้งาน Offline ได้บางส่วนหลังเปิดใช้ครั้งแรก

## ไฟล์ในโปรเจกต์
```
index.html         หน้าตาแอปทั้งหมด (HTML/CSS)
app.js             ข้อมูลเนื้อหาและฟังก์ชันการทำงานทั้งหมด
manifest.json      ข้อมูลแอปสำหรับ "เพิ่มลงหน้าจอโฮม"
service-worker.js  ทำให้ใช้งาน Offline ได้
icons/             ไอคอนแอปหลายขนาด (จากโลโก้ที่ให้มา)
```

## วิธีอัปโหลดขึ้น GitHub Pages (ไม่ต้องใช้คำสั่ง Git)

1. เข้า https://github.com แล้วสร้างบัญชี (ถ้ายังไม่มี)
2. กด **New repository** ตั้งชื่อ เช่น `anescare-app` แล้วเลือก **Public**
3. เข้าไปที่หน้า repository ที่สร้างไว้ → กด **Add file → Upload files**
4. ลากไฟล์และโฟลเดอร์ทั้งหมดในนี้ (`index.html`, `app.js`, `manifest.json`, `service-worker.js`, โฟลเดอร์ `icons/`) ไปวางแล้วกด **Commit changes**
5. ไปที่ **Settings → Pages**
6. ใต้ "Build and deployment" → Source เลือก **Deploy from a branch**
7. Branch เลือก `main`, โฟลเดอร์เลือก `/ (root)` แล้วกด **Save**
8. รอประมาณ 1-2 นาที จะได้ลิงก์ เช่น
   `https://ชื่อบัญชีของท่าน.github.io/anescare-app/`
9. เปิดลิงก์บนมือถือ แล้วลองกดเมนูเบราว์เซอร์ → **เพิ่มลงหน้าจอโฮม** (Add to Home Screen) เพื่อทดสอบว่าใช้งานเหมือนแอปได้จริง

## จุดที่ควรแก้ไขก่อนใช้งานจริง

ในไฟล์ `index.html` ส่วนแท็บ "ติดต่อ" (`id="contact-info"`) มีข้อมูลตัวอย่างที่ต้องแก้เป็นข้อมูลจริงของโรงพยาบาล:
- เบอร์โทร (`tel:1669` → เบอร์แผนกวิสัญญีจริง)
- ลิงก์ Line Official Account
- เวลาทำการ และจุดรับบริการ
- แผนที่ (ใส่ Google Maps embed ของโรงพยาบาลแทนกล่องตัวอย่าง)

## ข้อจำกัดของเวอร์ชันนี้

- ข้อมูลผู้ป่วย (วันผ่าตัด, Checklist, แบบประเมิน, ประวัติการสื่อสาร) เก็บไว้ใน**เบราว์เซอร์ของเครื่องนั้นๆ เท่านั้น** (localStorage) ยังไม่เชื่อมต่อฐานข้อมูลกลาง หากต้องการให้ทีมพยาบาล/วิสัญญีเห็นข้อมูลของผู้ป่วยแต่ละคนจริง จำเป็นต้องพัฒนาระบบ Backend/ฐานข้อมูลเพิ่มเติม
- เนื้อหาการให้ความรู้เป็นเนื้อหาทั่วไป ควรให้ทีมวิสัญญีแพทย์/พยาบาลตรวจทานความถูกต้องและความเหมาะสมกับบริบทของโรงพยาบาลก่อนเผยแพร่จริง
- ฟีเจอร์ "แชร์/ส่งออกให้ทีมวิสัญญี" ใช้ Web Share API หรือคัดลอกข้อความ ยังไม่ได้เชื่อมต่อส่งเข้าระบบเวชระเบียนโดยตรง
