# ดมยาแคร์ (AnesCare)

แอปเตรียมความพร้อมก่อน–หลังการระงับความรู้สึก สำหรับผู้ป่วยและญาติ
พัฒนาเป็น PWA (Progressive Web App) — ใช้งานผ่านเว็บเบราว์เซอร์ และสามารถ "เพิ่มลงหน้าจอโฮม" ให้เหมือนแอปจริงได้ ใช้งาน Offline ได้บางส่วนหลังเปิดใช้ครั้งแรก

## ไฟล์ในโปรเจกต์
```
index.html         หน้าตาแอปทั้งหมด (HTML/CSS)
app.js             ข้อมูลเนื้อหาและฟังก์ชันการทำงานทั้งหมด
manifest.json      ข้อมูลแอปสำหรับ "เพิ่มลงหน้าจอโฮม"
service-worker.js  ทำให้ใช้งาน Offline ได้
icons/             ไอคอนแอปหลายขนาด (จากโลโก้ที่ให้มา)
```

## วิธีอัปโหลดขึ้น GitHub Pages (ไม่ต้องใช้คำสั่ง Git)

1. เข้า https://github.com แล้วสร้างบัญชี (ถ้ายังไม่มี)
2. กด **New repository** ตั้งชื่อ เช่น `anescare-app` แล้วเลือก **Public**
3. เข้าไปที่หน้า repository ที่สร้างไว้ → กด **Add file → Upload files**
4. ลากไฟล์และโฟลเดอร์ทั้งหมดในนี้ (`index.html`, `app.js`, `manifest.json`, `service-worker.js`, โฟลเดอร์ `icons/`) ไปวางแล้วกด **Commit changes**
5. ไปที่ **Settings → Pages**
6. ใต้ "Build and deployment" → Source เลือก **Deploy from a branch**
7. Branch เลือก `main`, โฟลเดอร์เลือก `/ (root)` แล้วกด **Save**
8. รอประมาณ 1-2 นาที จะได้ลิงก์ เช่น
   `https://ชื่อบัญชีของท่าน.github.io/anescare-app/`
9. เปิดลิงก์บนมือถือ แล้วลองกดเมนูเบราว์เซอร์ → **เพิ่มลงหน้าจอโฮม** (Add to Home Screen) เพื่อทดสอบว่าใช้งานเหมือนแอปได้จริง

## เชื่อมต่อกับ Google Sheets (เก็บผลประเมิน/แจ้งปัญหาจากผู้ป่วยทุกคนไว้ที่เดียว)

ไฟล์ `Code.gs` ในโฟลเดอร์นี้คือ Google Apps Script ที่รับข้อมูลจากแอปแล้วเขียนลง Google Sheets ให้อัตโนมัติ

**ขั้นตอนติดตั้ง (ทำครั้งเดียว):**
1. สร้าง Google Sheet ใหม่ 1 ไฟล์ (ปล่อยว่างไว้ ไม่ต้องใส่หัวคอลัมน์เอง)
2. เมนู **Extensions → Apps Script**
3. ลบโค้ดเดิมทั้งหมดในหน้าต่างที่เปิดขึ้นมา แล้ววางโค้ดจากไฟล์ `Code.gs` แทน กด Save
4. กด **Deploy → New deployment** → เลือกไอคอนรูปเฟือง → เลือกประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. กด **Deploy** ระบบจะขอสิทธิ์เข้าถึง (Authorize) ให้กด Allow
6. คัดลอก **Web app URL** ที่ได้ (จะขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)
7. เปิดไฟล์ `app.js` หาบรรทัด:
   ```js
   const SHEET_WEBAPP_URL = "PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE";
   ```
   แล้วแทนที่ด้วย URL ที่คัดลอกมา จากนั้นอัปโหลด `app.js` เวอร์ชันใหม่ขึ้น GitHub ทับไฟล์เดิม
8. ทดสอบโดยเปิดแอป กดส่งแบบประเมิน/แจ้งปัญหา แล้วกลับไปดูที่ Google Sheet — จะมีชีตย่อยชื่อ `SatisfactionSurvey` และ `ConcernMessages` เกิดขึ้นอัตโนมัติพร้อมข้อมูลแถวใหม่

**เพิ่มหัวข้อประเมินภายหลัง:** แค่เพิ่มรายการใน `RATING_CATS` (ในไฟล์ `app.js`) หัวข้อใหม่จะถูกส่งไปพร้อมกับ key ใหม่ และ `Code.gs` จะสร้างคอลัมน์ใหม่ในชีตให้เองโดยอัตโนมัติ **ไม่ต้องแก้ไขโค้ด Apps Script เลย** ส่วนแถวข้อมูลเก่าก่อนหน้าจะเว้นว่างในคอลัมน์ใหม่นี้ (ปกติ เพราะผู้ป่วยคนนั้นยังไม่เคยถูกถามคำถามนี้)



## จุดที่ควรแก้ไขก่อนใช้งานจริง

ในไฟล์ `index.html` ส่วนแท็บ "ติดต่อ" (`id="contact-info"`) มีข้อมูลตัวอย่างที่ต้องแก้เป็นข้อมูลจริงของโรงพยาบาล:
- เบอร์โทร (`tel:1669` → เบอร์แผนกวิสัญญีจริง)
- ลิงก์ Line Official Account
- เวลาทำการ และจุดรับบริการ
- แผนที่ (ใส่ Google Maps embed ของโรงพยาบาลแทนกล่องตัวอย่าง)

## อัปเดตล่าสุด

- **เปลี่ยนโลโก้แอปอีกครั้ง**: ใช้ภาพดอกไม้สีฟ้าหน้ายิ้มที่แนบมาล่าสุด (ไม่มีลายน้ำติดมาด้วย จึงใช้ได้โดยตรง) สร้างไฟล์ครบทุกขนาด (48px–512px) ทดสอบแล้วยังคมชัดอ่านง่ายแม้ย่อเหลือขนาดเล็กสุดบนหน้าจอมือถือ

- **เปลี่ยนโลโก้เป็นภาพวาดต้นฉบับ**: ภาพดอกไม้สีฟ้าหน้ายิ้มที่ส่งมาให้ครั้งล่าสุดมีลายน้ำของเว็บสต็อกภาพ (pngtree) ติดอยู่ จึงไม่สามารถใช้ได้เนื่องจากปัญหาลิขสิทธิ์ จึง**วาดโลโก้ขึ้นใหม่เองทั้งหมด** เป็นดอกไม้กลีบสีฟ้า 8 กลีบพร้อมหน้ายิ้มสีเหลืองตรงกลาง โดยใช้โทนสีเดียวกับธีมแอป (`--brand-800` และ `--brand-500`) ทำให้เข้ากับแอปได้ดีและไม่มีปัญหาลิขสิทธิ์ ออกแบบเป็นสไตล์ค่อนข้างแบน (flat design) เพื่อให้ยังคมชัดอ่านง่ายแม้ย่อเหลือขนาดไอคอนเล็กสุด 48px บนหน้าจอมือถือ

- **เปลี่ยนโลโก้แอป**: ใช้ภาพดอกไม้สีฟ้าหน้ายิ้มที่แนบมาเป็นไอคอนแอป (จำง่ายและเข้ากับธีมสีใหม่) สร้างไฟล์ครบทุกขนาด (48px–512px)
- **เปลี่ยนธีมสีกลับเป็นโทนฟ้า #039EC0**: ปรับ `--brand-800` (สีหลักของปุ่ม/หัวข้อ) เป็น `#039EC0` ตามที่ระบุ พร้อมคำนวณเฉด 900/700/500/200/100 ล้อมรอบให้ครบชุด ส่วนสีเน้นในบางหมวดยังคงต่างจากสีหลักตามที่อนุญาต — สีเขียวมินต์ (`--teal-500 #2DBFA7`) ใช้กับสถานะ "สำเร็จ/เสร็จแล้ว" (เครื่องหมายถูก, แถบความคืบหน้า) และสีชมพู (`--pink-500 #F472B6`) ใช้กับดาวให้คะแนนและจุดเน้นความอบอุ่นใจ ให้แต่ละหมวดมีเอกลักษณ์ชัดเจนแทนที่จะเป็นสีฟ้าล้วนทั้งแอป
- **เพิ่มคำแนะนำเตรียมตัวเฉพาะหัตถการอีก 2 รายการ** ในคลังความรู้ > เตรียมตัวเฉพาะหัตถการ (รวมเป็น 3 หัตถการ):
  - **ผ่าตัดไส้เลื่อน (Hernia Repair)** — 9 หัวข้อ ครอบคลุมวิธีระงับความรู้สึก (Spinal / Local+Sedation), การงดอาหารน้ำ, ข้อควรระวังหลังฉีดยาชาไขสันหลัง, และอาการที่ต้องรีบพบแพทย์
  - **ผ่าตัดเนื้องอกหรือซีสต์ (Tumor/Cyst Excision)** — 11 หัวข้อ ครอบคลุมการงดสูบบุหรี่/แอลกอฮอล์ก่อนผ่าตัด, รายละเอียดเวลางดอาหารแยกตามประเภท (มื้อหนัก 8ชม./นมวัว 6ชม./นมแม่ 4ชม./น้ำใส 2ชม.), ข้อห้ามภายใน 24 ชั่วโมงหลังยาสลบ, และการดูแลตนเองเมื่อกลับบ้าน — เพิ่มเป็นหัตถการใหม่ในรายการเลือกที่หน้าแรกด้วย (เดิมยังไม่มี)
  - ทั้งสองหัตถการเชื่อมกับ Timeline และหน้าแรก "วันนี้ควรทำ" อัตโนมัติเหมือนส่องกล้องลำไส้ใหญ่ (เช่น ไส้เลื่อน → เตือนดื่มน้ำใสได้ถึง 2 ชม.ก่อนผ่าตัดในคืนก่อนผ่าตัด; เนื้องอก/ซีสต์ → เตือนงดบุหรี่ตั้งแต่ 7 วันก่อน และงดแต่งหน้า/ทาเล็บเช้าวันผ่าตัด)

  > **หมายเหตุสำหรับการเพิ่มหัตถการใหม่ในอนาคต**: เพิ่มข้อมูลที่ตัวแปร 4 ตัวในไฟล์ `app.js` โดยใช้ชื่อหัตถการเดียวกันเป็น key ทุกที่ — `PROCEDURES` (รายการเลือกที่หน้าแรก), `PROCEDURE_GUIDES` (คำแนะนำละเอียดในคลังความรู้), `PROCEDURE_TIMELINE_EXTRAS` (แทรกเข้า Timeline ตาม stage key: d7/d5/d3/d1/night/morning), `PROCEDURE_HOME_ALERTS` (แจ้งเตือนวันนี้ควรทำ ตาม diffDays)

- **แก้คำในหมวด "รู้จักการดมยาสลบ"**: เปลี่ยน "โดยมีวิสัญญีแพทย์ดูแลสัญญาณชีพ..." เป็น **"โดยมีวิสัญญีพยาบาลดูแลสัญญาณชีพ..."** ในคำอธิบาย "ดมยาสลบคืออะไร"
- **แยกพื้นที่ dropdown ให้เห็นชัดจากพื้นที่ปกติ**: ช่องที่ต้องแตะเพื่อเลือกจากรายการ (ช่องเลือกหัตถการที่หน้าแรก, ช่องพิมพ์ชื่อยาที่มี autocomplete) เปลี่ยนพื้นหลังให้ต่างจากช่องกรอกข้อความทั่วไป ส่วนรายการที่กดขยายออกมา (dropdown list, med suggestion, เมนูปรับขนาดตัวอักษร) เพิ่มเส้นขอบสีเข้มด้านบนให้เห็นชัดว่าเป็นกลุ่มเดียวกับช่องด้านบน
- **ขยายฐานข้อมูลยาเป็น 190 รายการ**: ผนวกรายชื่อยาจากไฟล์ "รายชื่อยาที่ผู้ป่วยมักรับประทานต่อเนื่อง" เข้ากับ `DRUG_DB` ครอบคลุมยาความดัน (7 กลุ่มย่อย) เบาหวาน (9 กลุ่มย่อยรวมอินซูลิน) ไขมัน หัวใจ ต้านเกล็ดเลือด/ต้านการแข็งตัวของเลือด เกาต์ หอบหืด/ถุงลมโป่งพอง ไทรอยด์ ต่อมลูกหมากโต กรดไหลย้อน ไต จิตเวช กันชัก และกดภูมิคุ้มกัน คำแนะนำเรื่องกินต่อ/หยุดยาอ้างอิงตามหลักการดูแลก่อนผ่าตัดทั่วไป (เช่น Beta-blocker/ยากันชัก/เบนโซไดอาซีปีน ห้ามหยุดกะทันหัน, SGLT2 inhibitor ควรหยุด 3-4 วันก่อนผ่าตัดกันภาวะ DKA, ACEI/ARB อาจงดเช้าวันผ่าตัดกันความดันต่ำ) **ควรให้ทีมวิสัญญีแพทย์ตรวจทานความถูกต้องของคำแนะนำแต่ละตัวก่อนใช้งานจริง** เพิ่ม/แก้ไขรายการได้ที่ตัวแปร `DRUG_DB` ในไฟล์ `app.js`
- **เพิ่มคู่มือ "เตรียมตัวก่อนส่องกล้องลำไส้ใหญ่" แบบละเอียด**: สรุปเป็น 11 หัวข้อ วางไว้ในแท็บ **คลังความรู้ > เตรียมตัวเฉพาะหัตถการ** เชื่อมกับ Timeline และหน้าแรกอัตโนมัติ
- **ปรับโครงสร้าง "คำแนะนำเฉพาะจากแพทย์"**: ย้ายจากการ์ดที่ฝังอยู่บนสุดของ Timeline มาเป็น**แท็บย่อยที่ 3** ในหน้าเตรียมตัว: `Timeline เตรียมตัว | Checklist วันผ่าตัด | คำแนะนำจากแพทย์` แสดงเต็มหน้าไม่ต้องกดขยาย ส่วนการเชื่อมต่อกับ Timeline (งดน้ำงดอาหาร → การ์ด "คืนก่อนผ่าตัด", พาญาติมาด้วย → การ์ด "เช้าวันผ่าตัด") และการแจ้งเตือนที่หน้าแรกยังทำงานเหมือนเดิม
- **เพิ่ม Timeline "5 วันก่อนผ่าตัด"**: แทรกระหว่าง "7 วันก่อน" กับ "3 วันก่อน" เพราะยาบางชนิดต้องหยุดพอดี 5 วันก่อนผ่าตัด ตอนนี้ Timeline มีทั้งหมด 6 ช่วง: 7 วันก่อน / 5 วันก่อน / 3 วันก่อน / 1 วันก่อน / คืนก่อน / เช้าวันผ่าตัด
- **รองรับ Pinch-to-Zoom**: แก้ meta viewport tag ที่เดิมล็อกไว้ เป็นอนุญาตให้ซูมได้สูงสุด 5 เท่า
- **แจ้งเตือนยาที่ "หยุดเช้าวันผ่าตัด" ครบถ้วนขึ้น**: เพิ่มเตือนในวันก่อนหน้าด้วยว่า **"กินยา X ได้ตามปกติวันนี้ (จะงดเฉพาะเช้าวันผ่าตัดเท่านั้น)"** (ขึ้นตั้งแต่ 3 วันก่อนผ่าตัด)
- **ปรับขนาดตัวอักษรทั้งแอปได้**: ปุ่ม "Aa" มุมขวาบน เลือกได้ 3 ระดับ (ปกติ/ใหญ่/ใหญ่มาก) จำค่าไว้ใน localStorage ปุ่มเมนูด้านล่างและหัวข้อด้านบนไม่ขยายตามเพื่อให้กดใช้งานง่ายเสมอ
- **แจ้งเตือนยาใน "วันนี้ควรทำ" ต่อเนื่องขึ้น**: ยาที่ควรหยุดล่วงหน้า X วัน ถ้าผ่านวันนั้นมาแล้วแต่ยังไม่ถึงวันผ่าตัด จะเตือนซ้ำทุกวัน กันพลาด
- **การ์ดหัตถการที่หน้าแรกยุบ/ขยายได้**: ค่าเริ่มต้นซ่อนคำอธิบายไว้ แตะหัวข้อเพื่อขยายดู ไม่ persist ข้าม session
- **แจ้งเตือนการจัดการยาก่อนผ่าตัด**: ปุ่มบันทึกคำสั่งแพทย์ **"กินต่อถึงเช้าวันผ่าตัด" / "หยุดเช้าวันผ่าตัด" / "หยุดล่วงหน้า...วัน"** ต่อยาแต่ละตัว เชื่อมกับ Timeline และหน้าแรกอัตโนมัติ ไม่ preselect ค่าใดๆ ไว้ล่วงหน้า
- **Dropdown เลือกหัตถการ**: เปลี่ยนจาก `<select>` แบบ native เป็น custom dropdown เพื่อคุมขนาดฟอนต์ได้เต็มที่ทุกอุปกรณ์
- **คำขวัญหน้าแรก**: เปลี่ยนเป็น "เตรียมพร้อม อุ่นใจเมื่อไปดมยา"
- **แก้ปัญหาแอปไม่อัปเดตอัตโนมัติ**: เปลี่ยน service worker จาก "cache-first" เป็น "network-first" พร้อมรีเฟรชอัตโนมัติเมื่อมีเวอร์ชันใหม่

> **คำแนะนำเรื่องยาและหัตถการเป็นข้อมูลทั่วไปสำหรับให้ความรู้เท่านั้น** ไม่ใช่คำสั่งทางการแพทย์เฉพาะราย ควรให้ทีมวิสัญญีแพทย์/พยาบาลตรวจทานความถูกต้องก่อนเผยแพร่ใช้งานจริง โดยเฉพาะยากลุ่มที่มีความเสี่ยงสูง ซึ่งตั้งใจให้ระบบแนะนำว่า "ต้องปรึกษาแพทย์เฉพาะราย" แทนการฟันธงตายตัว

## ข้อจำกัดของเวอร์ชันนี้

- ข้อมูลผู้ป่วย (วันผ่าตัด, Checklist, แบบประเมิน, ประวัติการสื่อสาร) เก็บไว้ใน**เบราว์เซอร์ของเครื่องนั้นๆ เท่านั้น** (localStorage) ยังไม่เชื่อมต่อฐานข้อมูลกลาง หากต้องการให้ทีมพยาบาล/วิสัญญีเห็นข้อมูลของผู้ป่วยแต่ละคนจริง จำเป็นต้องพัฒนาระบบ Backend/ฐานข้อมูลเพิ่มเติม
- เนื้อหาการให้ความรู้เป็นเนื้อหาทั่วไป ควรให้ทีมวิสัญญีแพทย์/พยาบาลตรวจทานความถูกต้องและความเหมาะสมกับบริบทของโรงพยาบาลก่อนเผยแพร่จริง
- ฟีเจอร์ "แชร์/ส่งออกให้ทีมวิสัญญี" ใช้ Web Share API หรือคัดลอกข้อความ ยังไม่ได้เชื่อมต่อส่งเข้าระบบเวชระเบียนโดยตรง
